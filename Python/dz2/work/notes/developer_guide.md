# Руководство разработчика

## Структура каталогов

`work/data` содержит базу данных и pickle-файлы справочников.
`work/library` содержит универсальные функции ввода и вывода.
`work/scripts` содержит специализированные функции отчетов, главный скрипт и
файл настройки.
`work/output` содержит текстовые отчеты.
`work/graphics` содержит графические отчеты.
`work/notes` содержит документацию.

## Модули

`library/io_tools.py` загружает таблицы из Excel, сохраняет и читает pickle, а
также выгружает табличные отчеты.

`scripts/reports.py` выполняет денормализацию справочников, строит текстовые
отчеты, сводную таблицу и графические отчеты.

`scripts/main.py` является главным модулем запуска:

```bash
python -m scripts.main
```

## Библиотеки

Используются Python 3, Pandas и Matplotlib. Код написан функционально, без
объектно-ориентированного программирования.
