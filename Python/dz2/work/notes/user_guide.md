# Руководство пользователя

## Назначение

Приложение формирует текстовые и графические отчеты по базе данных приюта для
животных. База хранится в каталоге `work/data`.

## Запуск

Из каталога `work` выполните команду:

```bash
python -m scripts.main
```

## Результаты

Текстовые отчеты сохраняются в каталог `work/output` в формате `.xlsx`.
Графические отчеты сохраняются в каталог `work/graphics` в формате `.png`.
При запуске также создаются файлы справочников `.pick` в каталоге `work/data`.

## Настройка

Основные пути и параметры интерфейса находятся в файле
`work/scripts/config.ini`.
