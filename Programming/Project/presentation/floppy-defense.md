# Тема работы

**Floppy** — настольное приложение для пакетной конвертации видеороликов в формат HEVC.

- вход: один или несколько локальных видеофайлов;
- обработка: перекодирование через FFmpeg;
- выход: файлы с суффиксом `_compressed`;
- интерфейс: GTK 4, запуск без ручного ввода команд.

**Вставить скриншот:** главное окно приложения с выбранными файлами.

# Цель работы

Разработать настольное приложение, которое позволяет пользователю выбирать видеоролики и перекодировать их в более эффективный формат хранения.

Ключевая идея:

- пользователь работает с графическим интерфейсом;
- приложение формирует параметры обработки;
- FFmpeg выполняет перекодирование;
- результат сохраняется рядом с исходным файлом.

# Требования к приложению

Приложение должно:

- выбирать один или несколько видеофайлов;
- поддерживать перетаскивание файлов;
- настраивать качество, разрешение и FPS;
- показывать прогресс;
- копировать метаданные;
- сообщать об ошибках.

# Предметная область

Видеофайлы могут занимать много места при хранении архивов, записей экрана и роликов с мобильных устройств.

Решение задачи — перекодирование видео с управлением ключевыми параметрами:

- видеокодек;
- качество;
- разрешение;
- частота кадров;
- перенос метаданных.

В работе используется HEVC/H.265 как формат более эффективного хранения видео.

# Анализ и выбор метода

Рассмотренные варианты:

- **FFmpeg** — универсальный инструмент для чтения, фильтрации и транскодирования медиафайлов;
- **HandBrake** — готовое графическое приложение с профилями кодирования;
- **Floppy** — специализированная оболочка под нужный сценарий пакетной обработки.

# Обоснование выбора

Выбранный подход:

- использовать FFmpeg как движок обработки;
- не реализовывать видеокодек вручную;
- вынести типовые параметры в графический интерфейс;
- оставить пользователю только основные настройки;
- добавить пакетный сценарий под задачу курсовой.

# Обоснование стека

- **Python** — язык реализации приложения и связующей логики.
- **GTK 4 + PyGObject** — графический интерфейс для Linux.
- **FFmpeg** — непосредственное перекодирование видео.
- **FFprobe** — получение параметров исходного файла.
- **ExifTool** — перенос метаданных после перекодирования.
- **python-ffmpeg** — асинхронный запуск FFmpeg и получение прогресса.

# Архитектура решения

Основные модули проекта:

- `app.py` — окно приложения, выбор файлов, обработка действий пользователя;
- `engine.py` — перекодирование одного файла;
- `utils.py` — работа с FFmpeg, FFprobe, ExifTool и выбором кодировщика;
- `requirements.txt` — Python-зависимости.

**Вставить схему:** UI → очередь файлов → FFmpeg/ExifTool → выходные файлы.
